# Contributing

Thanks for contributing to `safe-dotenv-check`.

## Development

```bash
npm test
```

Keep changes small and focused. If you add behavior, add or update tests in `test/check.test.js`.

## Pull requests

- explain the use case, not just the code change
- include tests for behavior changes
- keep CLI output changes intentional and documented

## Reporting bugs

Please include:

- the example env file shape
- the target env file shape
- the command you ran
- the actual output and expected output
